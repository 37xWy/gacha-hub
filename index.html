🛡️ Security, Privacy & Local Fetching Blueprint

🔒
Zero Server Architecture

Gacha Hub runs 100% on client-side HTML and vanilla JavaScript. There is no backend server, no cloud database, and no telemetry.

💻
Local-Only Storage

Uploaded JSON data is saved strictly to your browser's private localStorage sandbox.

🔑
Zero Password / Auth Risk

Gacha Hub will never ask for your Hoyoverse credentials. The game's authkey is a read-only token that expires in 24 hours.

🐍 Transparent Python Updater: Why We Don't Use Black-Box Exes

Many online tools ask you to download automated closed-source .exe files or run obfuscated PowerShell scripts that silently inspect your web cache. We strictly advise against that because untrusted executables can steal browser cookies, Discord sessions, or saved passwords.

⚠️ Critical Note on Banner URLs & Authentication:

When you open the in-game Warp History, Star Rail writes a temporary web log containing a getGachaLog URL with your temporary 24-hour authkey.

  • Special Event / Collab Banners: Certain special banners (like Collab Character / Light Cone warps) may generate a distinct URL query or require clicking directly into that banner's own history tab in-game so the log records the right authentication parameters.
  • Departure Warp (Starter 50-Pull Banner): This is the permanent beginner discount banner (20% off standard passes, guaranteed 5★ within 50 pulls). Once completed (50/50 pulls), the game closes the banner permanently. If your account was created long ago, Hoyoverse may no longer keep records for it since in-game logs only store recent months.
💡 How to Safely Inspect & Run Your Own Local Script:
  1. Open Honkai: Star Rail → navigate to the specific banner you want to log → open its Warp History records once so the fresh getGachaLog URL is written to your local game cache.
  2. Find your getGachaLog URL from the game web cache log (or use your own inspected web link).
  3. Have your AI (ChatGPT, Claude, Gemini) audit your local Python script before running to confirm it contains zero malicious payloads and only communicates with official Hoyoverse API endpoints.
  4. Run the script locally in your terminal. It saves clean, duplicate-free hsr_UID.json files directly to your folder.
  5. Drop or upload the resulting JSON into Gacha Hub to view your stats instantly!

import requests import json import os import time import random from urllib.parse import urlparse, parse_qs, urlencode, urlunparse def get_local_data(filename): if not os.path.exists(filename): return [], set() try: with open(filename, 'r', encoding='utf-8') as f: data = json.load(f) return data, set(item['id'] for item in data if 'id' in item) except: return [], set() def prepare_mimic_params(url_str): parsed = urlparse(url_str) query_params = parse_qs(parsed.query) clean = query_params.copy() for k in ['page', 'size', 'begin_id', 'end_id', 'gacha_type']: if k in clean: del clean[k] return parsed, clean def fetch_gacha_type(base_components, base_params, gacha_type, type_name, existing_ids, full_list): print(f"\nScanning {type_name} (Type {gacha_type})...") current_end_id = "0" page_num, new_items_count = 1, 0 scheme, netloc, path, _, _, fragment = base_components while True: p = base_params.copy() p['gacha_type'] = [str(gacha_type)] p['size'] = ['5'] p['end_id'] = [current_end_id] target = urlunparse((scheme, netloc, path, '', urlencode(p, doseq=True), fragment)) try: if page_num > 1: time.sleep(random.uniform(0.5, 1.2)) res = requests.get(target).json() if res.get('retcode') != 0: print(f" Note/Notice: {res.get('message')}") break items = res.get('data', {}).get('list', []) if not items: print(" -> Reached end of online history.") break batch = [] stop_early = False for it in items: if it['id'] in existing_ids: stop_early = True else: it['gacha_type'] = str(gacha_type) batch.append(it) existing_ids.add(it['id']) if batch: print(f" Page {page_num}: Found {len(batch)} new items...") full_list.extend(batch) new_items_count += len(batch) current_end_id = items[-1]['id'] page_num += 1 else: break if stop_early: print(" -> Reached previously archived local records.") break except Exception as e: print(f" Fetch Error: {e}") break return new_items_count def main(): print("=== HSR Warp History Local Fetcher ===") print("Note: If fetching Collab/Special warps, ensure you clicked that specific banner history in-game first!") check_collab = input("Check Collab Banners? (y/n) [default: n]: ").lower().strip() == 'y' url_input = input("Paste your getGachaLog URL: ").strip().replace('"', '') if not url_input: return parsed, mimic = prepare_mimic_params(url_input) # Detect UID uid = "Unknown" for gt in (['21', '11', '1', '12'] if check_collab else ['11', '1', '12']): try: t_p = mimic.copy() t_p['gacha_type'] = [gt] t_p['size'] = ['5'] r = requests.get(urlunparse((parsed.scheme, parsed.netloc, parsed.path, '', urlencode(t_p, doseq=True), parsed.fragment))).json() lst = r.get('data', {}).get('list', []) if lst and lst[0].get('uid'): uid = str(lst[0]['uid']) print(f"-> Detected Account UID: {uid}") break except: pass filename = f"hsr_{uid}.json" full_data, existing_ids = get_local_data(filename) print(f"-> Local file {filename} loaded with {len(full_data)} records.") banners = [(11, "Character Event"), (12, "Light Cone Event"), (1, "Stellar Warp")] if check_collab: banners.insert(1, (21, "Collab Character")) banners.insert(3, (22, "Collab Light Cone")) total_added = sum(fetch_gacha_type(parsed, mimic, b_id, b_name, existing_ids, full_data) for b_id, b_name in banners) if total_added > 0: full_data.sort(key=lambda x: int(x.get('id', 0)), reverse=True) with open(filename, 'w', encoding='utf-8') as f: json.dump(full_data, f, indent=2, ensure_ascii=False) print(f"\n[SUCCESS] Saved {total_added} new items to {filename}!") else: print("\n[UP TO DATE] No new items found.") if __name__ == '__main__': main()
